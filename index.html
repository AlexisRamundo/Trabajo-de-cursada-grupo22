App de gestión de tareas (To-Do List)

Esta aplicación web tiene como objetivo permitir a los usuarios gestionar eficientemente sus tareas cotidianas, organizando sus actividades mediante un sistema simple y ordenado.

Definición del Dominio: Entidad llamada Tarea

Cada elemento dentro del sistema representará una tarea individual y contendrá la siguiente estructura de datos:

Campo Tipo Descripción
ID int Identificador único de la tarea
Titulo string Nombre o título de la actividad
Descripcion string Detalle explicativo de lo que se debe realizar
Estado string Estado actual: Pendiente, En Progreso o Completada
Prioridad string Nivel de prioridad: Baja, Media o Alta
CreadoEn time.Time Fecha y hora en la que se dio de alta la tarea
Vencimiento time.Time Fecha y hora en la que vence la tarea
